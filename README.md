# Mijn Recepten v2.0.2

## Releasenotes
- Na het kopiëren van een recept probeert de knop **Naar CalorieTracker** CalorieTracker rechtstreeks te openen.
- De deeplink stuurt CalorieTracker naar **Voeding → Eigen recepten**.
- De bevestiging van de kopieeractie blijft zichtbaar.

## Bijzonderheden
- Na het openen tik je in CalorieTracker op **Recept ontvangen** om het klembord in te lezen.
- iOS kan de deeplink in Safari openen in plaats van in de geïnstalleerde Home Screen-webapp. Dit gedrag is niet volledig af te dwingen.
- Als de deeplink niet naar de app gaat, kun je CalorieTracker handmatig openen; de gekopieerde receptgegevens blijven op het klembord staan.
